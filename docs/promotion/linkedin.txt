Update: Codex Usage Tray v0.3.0 now includes Claude Code.

Two Windows tray icons show Codex and Claude's reported remaining quota. Faint provider symbols sit behind readable numbers; color gives a rough outlook on whether your recent pace will last until reset. One window brings together both quotas, local version checks, and optional instruction switches.

Routine monitoring and the color calculation use no AI inference. An optional AI review starts only after “Yes” and uses Codex allowance, including when reviewing Claude. Proposed instructions stay off until you enable them.

Claude support is experimental and currently limited to Claude Code 2.1.263. It covers the global five-hour and weekly windows, excluding model-specific limits and extra usage. An unverified client version pauses Claude quota reads.

Windows x64 beta; Japanese UI; JST time labels. Source + Windows ZIP on GitHub, with no separate Python installation. It uses your installed clients and existing logins. Independent of OpenAI and Anthropic.

The attached image is the original v0.2.0 demo. The release page below has the new two-provider demo, using synthetic data.

追記：Codex Usage Tray v0.3.0でClaude Codeにも対応しました。

CodexとClaudeの残量を、Windowsの通知領域に2つ並べて表示します。数字の後ろに各サービスのシンボルを薄く置き、色で「このペースならリセットまで持ちそうか」を概算。共通画面で残量・バージョン確認・任意の対策スイッチを管理できます。

通常監視と色の計算はAI推論なし。AI見直しは「はい」を押した場合だけで、Claudeの見直しもCodexのUsageを使います。追加指示は自分でONにするまで適用しません。

Claudeは現在2.1.263限定の試験対応です。全体の5時間枠・週間枠が対象で、モデル別制限・追加利用分は含みません。未確認の版へ更新されたら残量取得を停止します。

Windows x64・日本語UI・JST表示のベータ版です。Pythonの別途導入は不要。既存のクライアントとログインを使います。OpenAI・Anthropicの非公式アプリです。
