# Linux 試作版

v0.4.1 の共通 Python バックエンドを使う、Qt 6 のネイティブトレイです。
**Kubuntu 26.04.1 / KDE / Wayland / x86_64、Python 3.14.4、Qt 6.10.2** で起動・トレイ登録・Codex の実残量取得を確認しています。
Windows 版の配布 ZIP を実行する方式ではありません。

## 起動

Kubuntu 26.04 で依存物が入っていない場合：

```sh
sudo apt install python3-pyqt6 qt6-wayland
```

このリポジトリのルートから起動します。

```sh
./linux/run.sh
```

ウィンドウを隠して起動する場合は `./linux/run.sh --tray`。
閉じるボタンでは常駐を続け、各トレイの右クリックメニューの **終了** で終了します。
同じ保存先で再起動すると、既存のウィンドウを開きます。
トレイがないデスクトップでは画面を表示し、閉じる操作で終了します。

KDE のトレイ設定でアイコンを常に表示するように設定できます。表示位置は KDE が管理します。

## 今回の対応範囲

- Codex / Claude の2つのトレイアイコンとタブ。数字は最小残量、色は既存バックエンドの見通しです。上部の小さな C は Codex、A は Anthropic / Claude を示します。
- 残量・各枠のリセット時刻・消費ペースの見通し。通常は5分ごとに確認します。
- クライアント選択、15分ごとのバージョン監視と変更通知。
- VS Code / Insiders に登録済みの Linux 拡張機能と、`PATH` 上の `codex` / `claude` を検出します。
- クライアントが複数ある場合は選択が必要です。未導入・未ログイン・取得失敗では `?` を表示します。
- バックエンドの実行時間と出力を制限し、タイムアウト・終了時はそのプロセスグループを終了します。

通常の確認で AI 推論は使いません。認証は既存クライアントが扱います。
Claude は共通バックエンドと同じく、版を確認できた **2.1.263 以降の安定版で試験対応**です。Kubuntu の VS Code Insiders 拡張機能 **2.1.270** で、既存のログインを使った実アカウントの5時間枠・週間枠の取得を確認しました。
2.1.270 に同梱された制御メッセージの形式を確認し、従来と同じ `initialize` / `get_usage` だけで取得しています。バージョンの上限は固定せず、毎回の応答を検証します。非互換なら未確認表示とし、AI による代替取得は行いません。[確認根拠と限界](../docs/CLAUDE_METADATA_PROTOCOL.md)もご覧ください。

**AI 見直し・追加対策スイッチ・ログイン時起動の設定・拡張機能からのブランド画像読み込み・Linux 配布パッケージは、この試作版の対象外です。**
Linux UI から `review-run` や `ui-enable` は呼び出しません。既存の Windows 版には引き続きそれらの機能があります。
全機能の移植済みリリースとして扱わないでください。

Qt 6.7 以降と対応する PyQt6 が必要です。ARM64 の検出パスにはテストがありますが、実機検証は x86_64 のみです。
他のデスクトップでのトレイ対応は環境に依存します。[Qt の対応環境](https://doc.qt.io/qt-6/qsystemtrayicon.html)

## 保存先と削除

保存先は `${XDG_DATA_HOME:-$HOME/.local/share}/CodexUsageTray`。
`XDG_DATA_HOME` が相対パスの場合は `$HOME/.local/share` を使います。
`--data-dir /absolute/path` で変更できます。Claude の状態はその配下の `providers/claude` に分離します。

ログイン時起動の登録は行いません。削除する場合はトレイの **終了** を選び、ソースフォルダーを削除してください。
保存先のデータは別に残ります。不要な場合だけ削除してください。

## デモとテスト

デモは架空の残量を表示し、実クライアント・認証情報・ネットワークを使いません。
`--data-dir` を指定しないデモは、一時フォルダーを使って終了時に削除します。

```sh
./linux/run.sh --demo
PYTHONPATH=src python3 -m unittest discover -s tests
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s linux/tests -v
```

バックエンドの既存テスト、Linux の検出・XDG 保存先、両製品の画面更新、閉じる操作、未確認値、AI コマンドの拒否、タイムアウト時の子プロセス終了を検証します。
ウィンドウを閉じてトレイだけになった後も、定期タイマーによって両製品の残量とアイコンが繰り返し更新されることを、時間を短縮したテストで確認します。

Linux UI はシステムにインストールした PyQt6 / Qt を使い、それらを同梱しません。
依存物のライセンスは各配布元の条件に従ってください。
